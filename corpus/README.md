# Reference corpus

`vectors.json` contains fixed symbolic expectations, independent of the
implementation's table. The symbol reference is ITU-R M.1677-1 (2009), Annex 1.

`sos-650hz-20wpm.wav` is synthetic SOS, 650 Hz, 20 WPM, 8000 Hz mono signed
16-bit PCM, amplitude 0.6, with 180 ms leading and trailing silence. Its fixed
schedule is generated by `python3 maint/build-corpus.py` using only Python's
standard library. It never imports Ham::CW, and does not use the Perl signal
helper from the tests. Expected text: `SOS`; expected sample count: 15840.
The hard-keyed fixture intentionally differs from the generator's default
raised-cosine envelope.

The fixture and builder are original project material under the Artistic
License 2.0. No off-air audio or third-party recordings are included. Synthetic
noise, fading, impulses and small frequency variation are tested separately.
This corpus does not establish performance on real receivers or radio paths.
